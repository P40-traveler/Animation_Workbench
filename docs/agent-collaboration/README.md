# 外部 Agent 协作说明：交互网页维护说明

## 目标与读者

帮助当前工作台用户在 5—10 分钟内完成一次人类与外部 Agent 的交接：知道自己在页面做什么、给 Agent 发什么、Agent 怎样读取和回传，以及如何比较、采用和验收。以本机 Codex 或其他能够使用终端/HTTP和图像工具的 Agent 为主；不假设工作台已经配置自动调度、MCP 服务或生成 API。

## 打开方式

`interactive.html` 是无需构建、无外部依赖的单文件网页，可以直接用浏览器打开。工作台内另提供“Agent 协作说明”入口，指向构建中复制的 `/agent-guide.html`。此网页只做说明和本地模拟，不请求生产 API、不执行命令、不修改素材。

## 学习目标

1. 区分用户、工作台和外部 Agent 的职责。
2. 在界面保存规格并创建任务，将任务 ID 与明确交接文本发给 Agent。
3. 用项目 Python 客户端读取任务及图片、上传生成图片、提交候选。
4. 理解任务完成、格式通过、采用版本、人工验收是不同的判断。
5. 处理版本冲突、限域返工与远程 Agent 无法访问本机服务的情况。

## 内容模型与页面镜像

首页承诺：从“创建任务”到“收到可检查的候选”，一步一步知道下一步该由谁做。

贯穿案例：从零制作单方向角色攻击动作，用户随后标记 F005 的剑柄区域并返工。8 帧、128×128 和事件只是示例，不是固定产品限制。

建议课程路径（各屏独立，上一页/下一页可自由导航）：

1. **分清职责**：三方流程图可逐步推进。用户保存规格，平台冻结任务，用户手动把任务 ID 交给 Agent，Agent 读取任务并执行，平台接收候选，用户比较并验收。明确“点击创建任务不会自动唤醒 Agent”。检查题答案：创建任务之后，需要用户把任务交给外部 Agent。
2. **接上本机 Agent**：用户填写工作目录、服务地址和任务 ID，网页生成可复制的交接文本及分步命令。默认目录 D:\02_Working\Animation_workbench，默认地址 http://127.0.0.1:18765。先给非技术用户一段可直接发给 Agent 的话，命令放进“查看具体命令”。没有输入真实 ID 时不伪造可执行任务。检查题答案：任务包和其中选定的参考/边界帧是本轮依据。
3. **完成一轮协作**：按真实 UI 标签解释“保存修订”“任务”“确认规格并创建生成任务”“下载任务包”“版本”“采用此版本”“执行格式检查”“人工验收通过”“预检导出”。用可点击流程节点显示谁操作、输入、产物和下一步。解释 CLI 的 bundle --download-images 与网页仅下载 JSON 的区别。
4. **提交与返工**：提供 generate/repair 可切换的结果 JSON 示意，保留完整 frames、base_revision_id、image_id、稳定 frame id。repair 仅替换获准图片，不改变时长、顺序、偏移、事件、特效及未授权像素。只返回一张图片或文本不会自动成为候选。检查题答案：返工提交完整帧数组，仅改变获准内容。
5. **处理不同步与交付**：版本演练允许模拟用户在等待 Agent 时保存新版本，观察旧任务结果可以成为候选却不自动覆盖当前版本，使用过期 expected_current_revision_id 采用会返回 409。解释 422 和取消任务。远程模式说明 localhost 指向 Agent 自己的机器，远程文件交接后必须在本机注册图片、生成真实 image_id 并提交，不声称已实现公网接入。

末尾提供简短操作清单及重置学习进度。概念收藏采用“任务快照、候选版本、稳定帧 ID、修改范围、人工验收”，不使用积分或强制关卡。

## 交互与状态约定

- 学习导航、流程模拟和版本冲突演练只影响页面内状态。
- 本地 localStorage 仅记录章节和完成的检查题；不保存任务 ID、工作目录、URL或复制文本。存储不可用时仍可使用。
- 命令生成器使用 PowerShell 字符串转义，校验任务 UUID，URL只接受 http/https且不得包含账号密码；不得将输入直接拼成可注入的 shell 文本。
- 复制动作要有成功/失败提示；file:// 或内置浏览器不支持 Clipboard API 时提供可选中的文本和手动复制提示，不依赖原生 prompt/confirm。
- 真实接口代码仅作为可复制文本展示；页面不 fetch 服务，不上传素材，不写数据库。
- 选项更改只更新对应命令/图示，不重建整页或丢失输入焦点。
- 支持键盘、窄屏和 prefers-reduced-motion；没有无限循环动画或自动播放声音。

## 最终 HTML 内容镜像

首页标题“把下一步，交给 Agent。”，承诺“你定要求，Agent 做素材，工作台保留每一次候选”。首页先展示三个可点击节点：你建任务、你发给 Agent、你刷新比较。正文为五个独立屏幕：

| 屏幕 | 标题与核心机制 | 可操作内容 | 非阻断检查题答案 |
|---|---|---|---|
| 01 分清职责 | 任务保存了，还需要你把它交出去 | 用户 / 工作台 / 外部 Agent 流程节点 | 手动交接任务 ID 和要求 |
| 02 交给 Agent | 复制一段话，把这一轮交清楚 | 工作目录、根 URL、UUID 生成交接文本；展开命令；自动或手动复制 | 以任务快照、选定参考和边界帧为依据 |
| 03 收回候选 | 收到图片，还差一次正式回传 | 六步流程节点显示执行者、输入与产物 | 处理未保存草稿后刷新 / 重连 |
| 04 局部返工 | 只改剑柄，就把范围说到像素 | generate / repair 切换，模拟越权开关，完整八帧 JSON | 提交完整帧数组，仅改授权内容 |
| 05 比较与交付 | 旧任务也能交回候选，当前版本不会被悄悄覆盖 | 保存 v2 / 提交候选 / 采用 / 刷新 / 重置 | 采用后还需格式检查和人工验收 |

章节导航可直接跳转，不要求先答题。每道题答对后收藏相应概念：任务快照、选定上下文、候选版本、稳定帧 ID / 修改范围、人工验收。答错只解释误区，不阻止继续。

最终交付清单：比较采用 → 格式检查与美术检查 → 人工验收 → 取消草稿导出、预检并处理时序损失。正式说明区明确旧基础候选可以采用，但会让当前内容不再包含后来版本的部分修改，历史版本仍保留；没有自动合并，也可基于最新版本重建任务。

## 技术、边界与素材

- 单 HTML 内联 CSS / JavaScript，零库、零 CDN、零外部字体、零图片依赖。没有服务请求或命令执行代码。
- localStorage 键为 `interactive-explainer:agent-collaboration:v1`，只写 `{page, completed}`。读取时校验页码和题目键；路径、URL、任务 ID 与复制文本始终只留在页面内存。存储不可用时仍能学习。
- URL 只允许 http/https 根地址，不含用户信息、路径（除 `/`）、查询或 hash；目录禁止换行和 NUL；命令参数统一 PowerShell 单引号包裹，内部 `'` 替换为 `''`。URL 参数在子命令前。
- 模拟不访问真实项目，不检查实际任务存在性；填 UUID 后仅说明“文本就绪”，不显示连接成功。输入合法也不能证明 Agent 已具备图像工具。
- 协作流程与帧授权用 HTML 表示，示意人物是内联 CSS 几何图形。没有生成图片；本主题需要精确可选文本与状态关系，额外图像不会改善理解。
- 沿用既有工作台的界面实现；不在共享说明中复制受限风格文件内容。保持原生语义按钮、可见焦点、aria-live 输出与章节焦点定位。窄屏改为顶部章节网格；无自动播放或强制动效，支持 reduced-motion。
- 复制回退使用 textarea.focus()/select()，不依赖原生 prompt/confirm。结果 JSON 的示例占位符明确不是可提交 ID；示例时长和偏移不能直接覆盖真实 repair 基础值。
