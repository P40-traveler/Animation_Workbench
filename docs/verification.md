# v0.1 验收记录

验收日期：2026-10-30。环境：Windows，Python 3.12.7，Node.js 24.14.1。本轮先形成设计与接口，再由前后端两个 GPT-6 Astra medium 子 agent 分别实现，由协调者进行独立集成和浏览器验收。只有前端实现 agent 阅读前端风格文件。

## 启动环境修复（用户反馈后）

用户双击 start.cmd 时出现 `No module named fastapi`。已复现普通 Windows PATH 优先选择 MSYS2 Python，而此前 Codex 验收环境优先选择 Anaconda。原启动检查没有覆盖这种环境差异。

启动器现会筛选兼容的原生 Windows Python，在项目 `.venv` 中创建独立环境并安装依赖，之后始终使用该解释器的绝对路径。安装前检查环境确实位于本项目；不使用全局 pip，不要求激活 Conda。依赖检查通过且 requirements 哈希未变化时跳过安装。已有且未过期的前端构建也直接复用。start.cmd 支持转发参数并保留失败退出码。

本次实际验证：

- 使用 Machine+User PATH（MSYS2 在先），启动器正确跳过它并用 Anaconda 3.12.7 创建 `.venv`。
- 项目环境安装完成，移除 Anaconda PATH 后 SSL、SQLite 和 FastAPI 仍能加载。
- 使用独立环境重跑后端 14 项测试及公共 HTTP 的 8 组流程检查，均通过。
- 从 `C:\Windows\System32` 经实际 `cmd.exe /d /c ...\start.cmd` 启动，健康检查和前端页面均返回 HTTP 200。
- PATH 仅保留 Windows 系统目录时，`-SetupOnly` 二次准备通过，无重新安装或前端构建。
- 修复了经 cmd 间接启动旧 PowerShell 时可能无法加载 Get-FileHash 的兼容问题，改为 .NET SHA256。

项目环境实际安装版本：FastAPI 0.162.0、Uvicorn 0.54.0、Pillow 12.3.0、Pydantic 2.14.2、pytest 8.4.2、httpx 0.28.1。依赖已装入当前项目，用户无需再手动执行安装命令。验收服务在交付前停止，避免与用户再次双击冲突。

## 浏览器实际操作

在 Codex 内置浏览器打开同源本地服务，完成以下操作：

1. 新建“首版验收 · 剑士”项目，载入明确标记的程序测试素材。
2. 选择攻击动作第五帧，进行一次像素编辑并保存为新修订。
3. 标记第五帧问题，创建绑定该帧的返工任务。
4. 通过 `agent_client.py` 下载任务及图片，提交明确标记“未改图”的接口验收候选。它用于验证交接，不作为真实修复效果证明。
5. 页面刷新后，确认候选进入列表而原工作版本不被覆盖，随后采用候选。
6. 执行格式检查。固定帧数导出显示特效时序损失，未接受损失时禁止下载。
7. 改用保留全部变化，从页面下载 ZIP。回读得到 12 张合成帧、800ms 总时长、14 个 ZIP 文件，校验无损坏。
8. 上传实际 PNG 参考图并保存，确认仍停留在 F005、400ms；切换棋盘格预览，背景不进入图片内容。

已修复在浏览器发现的问题：原生 prompt 不受支持（改应用内对话框）、保存与异步加载覆盖草稿的风险、切帧图片加载期间可能写错图、跨项目残留 action ID、选区越界与移动后定位、保存后跳回第一帧。

截图：`outputs/workbench-preview.jpg`。页面实际下载的示例包：`outputs/ui-verified-export.zip`。该包是验收用草稿，不是用户最终认可的美术作品。项目中的程序测试素材和验收历史保留，便于用户复查。

## 当前边界

- 真实生成由外部 Agent 完成。没有自动调用付费服务，没有读取密钥，也没有内置小模型视觉质检、自动去背景或自动视觉返工。
- 上下文由结构化规格和规则组装。只检测可靠的显式帧数/画布键值冲突，任意自然语言矛盾仍需用户复核。参考用途目前支持身份、画风、姿势和武器。
- 像素复制粘贴使用工作台内部剪贴板。撤销重做仅覆盖当前帧尚未提交的像素编辑，切帧或提交后清空；历史版本另行保留。
- 浏览器已实测铅笔、保存、参考上传、候选及导出等主流程；尚未逐项手工验收所有像素工具和长时间连续操作。几何边界有自动测试，但不等于完整编辑器耐久测试。
- 时间精度为整数毫秒；首版不支持任意分数帧率精确表示、骨骼动画、root motion、完整专业编辑器工程兼容或自动遮挡分层。
- 特效图层独立计时、普通 alpha 合成；没有任意旋转、变形及高级混合模式。统一缩放使用最近邻，不等于自动像素美术重绘。
- 单机使用，未做多人权限或公网部署。图片不可变，元数据使用 SQLite；大规模资产量及大画布性能尚未做压力测试。

下一阶段应使用用户真实角色参考，完成一条新动作的生成与返工，记录人工修整时间和总成本，再评估小模型辅助质检。当前验收证明工作台流程可以运行，不证明某个生成模型的动作质量。
