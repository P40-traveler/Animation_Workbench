# 实施说明

用户已确认设计v1.0，实施阶段0至3。具体契约见API_CONTRACT.md。

- 默认端口改为18765：本机8765实际无法绑定，18765已验证可用。不更改系统网络设置。
- PNG上传、切片与像素笔画采用请求返回结果，界面显示忙碌；序列精度转换与导出采用持久化后台任务。这样导入与像素笔画能直接返回素材信息和修订号，避免同一笔编辑跨多个版本异步提交。较大的图集建议先降低精度。
- 源文件保留原始字节，派生PNG按新asset ID存储。SQLite版本文档带revision，撤销恢复引用，不原地重写图像。
- 像素编辑默认当前曝光独立副本。第一版不提供批量重写共享源的按钮，复用修订帧通过素材库替换其他曝光；旧版本始终保留原引用。
- 洋葱皮支持前/后颜色区分及透明度，不提供任意颜色配置。高质量人物动作、自动分层、自动补帧不属于第一版。
- 规则切片会给出边界非透明警告；示例长剑试稿跨格问题刻意保留并标记，以展示检查流程，未宣称成品。
- 任意角度旋转时浏览器Canvas与Pillow可能存在像素边缘差异，正式导出以后端预览为准。
- 时间并集模式保留独立特效曝光边界；固定帧数模式显式提示可能遗漏变化，事件与原始时序保留在manifest。
- 日常启动只用已构建前端与专用Python环境。完整npm锁文件和源码保留，开发时npm ci可还原前端依赖。
