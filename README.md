# 帧间 · 角色动画素材工作台

双击 **启动工作台.cmd**，打开 http://127.0.0.1:18765 。浏览器关闭不会停止服务；需要停止时运行停止工作台.ps1。

前端已构建，日常使用不需要运行 Node。数据保存于 data/，日志位于 logs/service.log。

## 使用流程

1. 新建项目，添加角色、动作或打开已有版本。
2. 图层面板 → 导入 PNG。多张图片加入序列；图集先设置行列、边距、格大小或手工框选。边界警告需检查，不能自动修复跨格剑光。
3. 规范面板分别设置画布、pivot 和角色身体目标尺寸。图层可设置源锚点、偏移、缩放和旋转。拖动画布改变当前图层的位置；变换范围可选整个片段或当前曝光。
4. 底部播放、单步、调时长，开启洋葱皮。帧面板设置出伤等事件，比较版本或拼接动作查看衔接。
5. 独立剑光以特效图层导入。设置 start_ms 和曝光时长，使它在指定角色帧之间播放，结束默认隐藏。
6. 问题面板框选区域、描述问题；帧编号用于沟通，内部 ID 保证重排后批注仍跟随原帧。
7. 生成面板填写方案、参考图，组合并编辑最终提示词，保存请求。告诉 Codex 请求 ID；Codex 通过 API 读取、生成并回传。不直接调用图像生成 API。
8. 精度转换使用原素材身体参考框，同一图层序列按统一比例缩小。原图保留。转换后可以进入像素微调；当前素材编辑自动建立曝光副本。
9. 导出面板运行检查。PNG 序列、图集、逐层结果和 JSON 一起打包。默认阻止越界；固定帧数模式可能漏掉短特效变化。

更换图层或版本前保存。未保存的 UI 编辑不提供给 Codex；后端只渲染已保存版本。另一端修改时界面会刷新，或在本地有未保存编辑时提示冲突，可以另存版本。

Ctrl 浏览器缩放可能影响显示，画布放大通过工具内倍率控制。大图像素编辑请先降低精度；每笔最多250000像素。

## 数据与备份

“备份全部项目”下载包含数据库、原图、派生图片和导出的 ZIP。恢复：先停止服务，将备份内容解压到新的 data 目录，保留现有 data 作为备份，再启动。不要在服务运行时替换数据库。

## 协作与开发

- 在线 API 契约：/docs 和 /openapi.json。
- [接口说明](docs/API_CONTRACT.md)、[Codex 使用说明](docs/CODEX_USAGE.md)。
- 前端：frontend/，构建 npm ci 后 npm run build。
- 后端：backend/，启动 .venv/Scripts/python -m uvicorn backend.app:app --host 127.0.0.1 --port 18765。
- 测试：.venv/Scripts/python -m pytest tests -q（可指定新的 --basetemp 目录）。
- 不写游戏 Assets，不自动验收人体动作与武器形态。后端导出预览是正式合成依据，任意角度旋转可能与浏览器预览有边缘差异。
